# Backend Feature Docs

## Purpose
This folder contains implementation-ready feature documents for backend development.

## Sprint 1 Scope (M1 + M2 partial)
Sprint 1 includes these tickets from the backend backlog:
- BE-M1-01: DRF, JWT, and environment settings
- BE-M1-02: API v1 routing and health contract
- BE-M2-01: Core models and migrations
- BE-M2-02: Customers API
- BE-M2-04: Workorders API and lifecycle transitions

## Usage Guidance
1. Read the sprint overview first.
2. Implement in dependency order listed in the overview.
3. Treat acceptance criteria as the definition of done for each feature.
4. Complete tests in each doc before moving to the next feature.
