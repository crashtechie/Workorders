# Frontend Logs

This folder contains frontend-specific diagnostic logs.

## Typical Contents

- Frontend Docker build failures
- Nginx/static serving runtime errors
- Frontend build tool output

## Current Examples In This Folder

- `docker-build-errors_20260527_190550.log`

## Usage Notes

- Add one log file per command run when troubleshooting.
- Use timestamped filenames for sorting.
- Remove obsolete logs after issues are resolved, unless needed for historical reference.
