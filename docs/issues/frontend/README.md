# Frontend Issues

Use this folder for frontend-only issue records.

## Includes

- Build pipeline issues for frontend assets
- Nginx/static delivery problems
- Client routing and page rendering defects
- Frontend container build/run issues

## Excludes

- Backend API-only issues
- Cross-service incidents (store those in `../shared/`)

## Typical Record Fields

- Affected page/route
- Browser and environment details
- Error output or screenshots/log snippets
- Resolution and regression checks
