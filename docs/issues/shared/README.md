# Shared Issues

Use this folder for issues that span backend, frontend, or repository-wide tooling.

## Includes

- Contract mismatches between frontend and backend
- Build/release workflow issues affecting multiple services
- Documentation/process gaps impacting the whole project
- Infrastructure and container orchestration issues

## Typical Record Fields

- Components impacted
- Timeline of incident/discovery
- Coordinated fix plan across services
- Validation checklist for each affected area
