# Backend Issues

Use this folder for backend-only issue records.

## Includes

- API behavior bugs
- FastAPI/Uvicorn runtime issues
- Dependency and environment issues affecting only backend
- Backend container build/run defects

## Excludes

- Frontend-only UI issues
- Cross-service incidents (store those in `../shared/`)

## Typical Record Fields

- Endpoint(s) impacted
- Request/response examples
- Relevant backend logs
- Fix details and verification notes
