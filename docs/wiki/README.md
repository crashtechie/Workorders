# Project Wiki

This folder is the long-lived knowledge base for the Workorders repository.

## Purpose

- Capture stable reference documentation.
- Keep operational and architectural knowledge discoverable.

## Subdirectories

- `backend/`: backend architecture, APIs, and operations reference.
- `frontend/`: frontend architecture, build/runtime behavior, and operations reference.
- `shared/`: repository-wide standards, conventions, and onboarding information.

## What Belongs Here

- How-to guides
- Architecture overviews
- Troubleshooting playbooks
- Common workflows

## What Does Not Belong Here

- Time-limited issue triage notes (place those in `../issues/`)
- Raw logs (place those in `../logs/`)
